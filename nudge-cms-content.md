## Framer CMS tips

1. Remix Nudge → new project (don’t edit the live preview URL).  
2. Open **CMS → Projects** (or whatever the collection is named).  
3. Duplicate a demo item 2× so you have 6 slots.  
4. Paste fields from this file; upload covers.  
5. For placeholders, set a **Draft** or **Coming soon** flag if the template has one; otherwise grey the CTA.  
6. Update Home hero name from Bejaman → Danny Varghese.  
7. Publish to a new domain or `dannyvr.framer.website` / custom domain.
