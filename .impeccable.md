# Design Context — danny-me

## Product
Personal portfolio for Danny (design technologist). Homepage centers a sticky folder-stack of featured projects (Lola, ops tools, concepts). Signature: colored folder cards on grid paper with pull-wire invite and scrub-through stack.

## Audience
Hiring managers, design leads, collaborators scanning for craft + shipped product work.

## Visual system
- Surfaces: grid paper (`--bg-folio`), folder fills per project tone, ink on fill
- Type: DM Sans portfolio-wide; Pixelify only for Lola wordmark/title when marked
- Radius: folder tab/body tokens; soft xs on media wells
- Motion: sticky scrub (CSS transform), reduced-motion → static stack
- Media wells: fixed 16:9 — never stretch/crop to fill card height

## Folder card spacing intent (arrange)
Use the site spacing scale (`--space-1`…`--space-8`). Inside each card:
- **Tight** within identity (progress → date → title → meta)
- **Open** before story (blurb), proof (metric), actions (CTAs), then tags
- Do not equalize all gaps — rhythm creates hierarchy
- Keep media at natural 16:9; align copy and media to a shared top edge
